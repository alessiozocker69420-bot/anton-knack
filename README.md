# ANTON KNACK 2 – iPad Starter

Dieses Projekt ist eine iPad-freundliche GitHub-Pages-Webapp.

## Enthalten
- Startseite mit Link-Öffner für ANTON und andere Websites
- HTML-, CSS- und JavaScript-Editor für eigene Testseiten
- isolierte lokale Live-Vorschau
- responsive Oberfläche für Safari/iPad

## Lokal testen
`index.html` im Browser öffnen.

## GitHub Pages veröffentlichen
1. Repository `anton-knack-2` öffnen.
2. `Add file` → `Upload files`.
3. Alle Dateien dieses ZIPs hochladen und committen.
4. `Settings` → `Pages` → `Deploy from a branch`.
5. Branch `main`, Ordner `/(root)`, speichern.

## Ehrliche technische Grenze
GitHub Pages ist statisches Hosting. Es kann keinen dauerhaften Chromium-Browser hosten. Eine normale Webseite kann außerdem wegen Browser-Sicherheitsregeln nicht den DOM, die Console oder den Netzwerkverkehr eines fremden Tabs (z. B. anton.app) inspizieren. Dafür wäre ein separat gehosteter Remote-Browser mit Sicherheits- und Datenschutzkonfiguration nötig. Kostenlose Anbieter garantieren dafür normalerweise keine unbegrenzte Laufzeit.

Dieses Projekt enthält keine Funktion zum Abgreifen von Passwörtern/Cookies, Übernehmen von Sitzungen, Umgehen von Schutzmaßnahmen oder automatischen Lösen von Aufgaben.
